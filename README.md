# Registro de pedidos - Brana

Formulario web (un solo archivo `index.html`) para registrar pedidos de Shalom, Olva, retiro en tienda y entrega a domicilio.

- Sin servidor ni instalación: abre `index.html` en el navegador.
- Los datos se guardan en el navegador de cada persona (localStorage).
- "Nuevo pedido" es público; Pedidos, Agencias y Papelera piden usuario y contraseña.
- `prompt-formulario-pedidos.md`: prompt para replicar el formulario en otra cuenta de Claude.

Para publicarlo en GitHub Pages: Settings > Pages > Branch `main` > carpeta `/ (root)`.
